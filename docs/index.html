    Data. Payroll jobs: U.S. Bureau of Labor Statistics, Current Employment Statistics (state and metro), via FRED. Job postings: Indeed Hiring Lab job postings index (seasonally adjusted, 7-day average, Feb 1 2020 = 100). An index measures the trend in postings, not the number of open jobs.

    Method. Python (pandas) cleans the files and loads them into SQLite; the analysis is written in SQL (CTEs, window functions). Code, queries and results: github.com/resulisik/california-jobs-by-sector.
